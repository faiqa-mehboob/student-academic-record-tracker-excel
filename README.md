
# Student Academic Record System

An automated grading tracker built in Excel for 15 students across four subjects (English, Maths, Science, Computer). Calculates totals, averages, percentages, letter grades, pass/fail results, and class rank automatically.

## Features
- Total and average marks computed with SUM/AVERAGE
- Percentage calculated from total marks
- Automated letter grading (A+ to F) using nested IF statements
- Pass/Fail result determined from grade
- Class ranking via RANK.EQ
- Summary section: total students, pass/fail counts, highest/lowest percentage, class average

## Tools Used
- **Microsoft Excel** — AVERAGE, SUM, nested IF, RANK.EQ, summary statistics
